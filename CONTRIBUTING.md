# Contributing

Use Python 3.11+ and run the Python/Node synthetic tests before submitting a change. Keep original WeChat files read-only, authenticate keys/pages before decoding, preserve raw source rows, and distinguish unavailable extensions from successful integrity checks.

Never commit or attach real keys, account paths, contacts, chat archives, decrypted databases, cookies, logs with private output, or Tencent application binaries. Use generated fixtures in bug reports. Report which OS, architecture and WeChat version were actually tested; do not equate a CI build with live WeChat acceptance.

Public binary installers are a separate deliverable with native signing and OS integration requirements. The current release is source-based Python tooling.
