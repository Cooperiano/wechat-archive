# Security

Do not post encryption material or private conversations in public issues. Use GitHub private vulnerability reporting when available, or contact the maintainer privately without including raw keys.

The tool handles private local plaintext. Source paths are read-only, output roots are separate and source-bound, and the loopback viewer requires a per-launch token. Only use the tool with data you own or are authorized to access. Close the server when finished; do not expose or proxy it to a network.

Unknown schema/crypto settings fail rather than being treated as empty history. The Mac bootstrap wrapper is experimental and requires explicit restart authorization; recovery failures must be handled before reusing the account.
