# v0.1.0 预览交付范围

交付的是 MIT 开源源码、一个公共 Python wheel、两个 Python 便携启动包。它们需要 Python 和首次依赖安装；不包含原生签名安装包、Microsoft Store 认证或 macOS 公证交付。

已接入：配置化已有密钥导入，原生凭据保护，显式平台初始化，DB/WAL 快照，全消息表解析、原始行保留和本地分页浏览。

验收分层：

| 层 | 验证方式与边界 |
| --- | --- |
| 来源与路径 | 合成重叠路径、`~`、manifest 越界、symlink / hardlink 与来源绑定测试 |
| 数据与 WAL | 合成数据库、提交边界、损坏拒绝、旧输出保留；原生 AES 公开测试向量 |
| 凭据 | 模拟钥匙串事务；Windows DPAPI 的运行支持不等于真机完整流程验收 |
| 页面 | 内存合成 DOM：刷新令牌、错误清屏、异步乱序、分页等待、时间与字面渲染；HTTP 鉴权及查询测试 |
| 包 | wheel 与两个启动包的构建、安装导入与命令入口检查 |
| 初始化 | 原底层有此前真机证据；新的恢复封装仍实验性，未重复真机取钥 |

尚未完成：真实浏览器界面、各微信版本 Windows/Mac 实机初始化兼容矩阵、持续后台增量、媒体本体、跨设备合并和原生桌面安装包。构建或 CI 通过不代替这些验收。

后续先补真实界面和取钥恢复验收，再开发增量与媒体；原生桌面包须使用稳定应用身份和平台签名流程单独交付。
